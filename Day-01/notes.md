## 📚 Topics Covered

1. Introduction to Programming Languages

The session introduced the basic differences between C, Java, and Python.

- C — commonly used for system-level and low-level programming.
- Java — widely used for application development with platform independence.
- Python — a high-level, beginner-friendly language known for its simple syntax and productivity.

2. Strings in Python

A string is a sequence of characters.

Python allows strings to be written using:

- Single quotes: `'Hello'`
- Double quotes: `"Hello"`
- Triple quotes: `'''Hello'''` or `"""Hello"""`

3. print()

The `print()` function is used to display output in Python.

Example:

```python
print("Hello, World!")
